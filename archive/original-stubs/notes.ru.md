# Заметки

## Git

Git сохраняет историю изменений проекта. Благодаря коммитам можно понять, что и когда менялось, а также безопасно экспериментировать.

## GitHub Pages

GitHub Pages публикует статические сайты прямо из репозитория. Для Jekyll-сайта достаточно включить Pages в настройках репозитория и выбрать источник публикации.

## Jekyll

Jekyll преобразует Markdown-файлы в готовые HTML-страницы. Это удобно для простых сайтов, блогов и документации.
