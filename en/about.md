# About

I have worked in&nbsp;IT since 2017 and&nbsp;at SMS-Information Technologies since September 2020. I started with&nbsp;software implementation for&nbsp;customers, then moved into build automation, application deployment and&nbsp;internal infrastructure.

## What I do

- Configure TeamCity builds, tests and&nbsp;deployments for&nbsp;.NET, Python and&nbsp;frontend applications. Write PowerShell, Bash and&nbsp;Python scripts and&nbsp;work with&nbsp;build dependencies and&nbsp;the REST API.
- Deploy applications to&nbsp;Kubernetes and&nbsp;Docker/Compose. Recent work includes a new Keycloak test environment with&nbsp;database-migration checks, and&nbsp;Portainer with&nbsp;persistent storage, HTTPS and&nbsp;domain authentication.
- Operate Linux and&nbsp;Windows Server, PostgreSQL, Nginx/IIS and&nbsp;S3/MinIO. Prepare test environments and&nbsp;configure backup and&nbsp;restore procedures.
- Configure authentication through Keycloak/OIDC and&nbsp;ADFS, monitoring with&nbsp;Zabbix and&nbsp;Grafana, and&nbsp;logging with&nbsp;ELK and&nbsp;Graylog.

## How I work

I like tracing a problem across the whole system: from the build and&nbsp;application configuration to&nbsp;networking, authentication and&nbsp;the database. After fixing it, I try to&nbsp;leave a check, script or&nbsp;runbook so the same failure is easier to&nbsp;catch next time.

In 2026, alongside my main job, I worked on a university HPC project using Linux, Slurm, Ceph/CephFS and&nbsp;SONiC networking. This was additional project work, not a separate period of&nbsp;employment.
